# Module 07: Phòng họp, Sinh nhật, Quản trị hệ thống
- **Trưởng nhóm:** Tô Thanh Tân (DA)
- **Độ khó:** 0.4 / 0.8

## 1. Mục tiêu & Nghiệp vụ
- Quản trị hệ thống: Cơ cấu tổ chức (Đơn vị, Phòng ban), Chức vụ, Hồ sơ Cán bộ nhân viên (CBNV).
- Phân quyền người dùng (Role-based Access Control - RBAC).
- Quản lý đặt phòng họp: Lịch họp tuần, thiết bị phòng họp, chống trùng lịch.
- Quản lý sự kiện và thông báo sinh nhật tự động cho CBNV.
- Lưu trữ tài liệu cuộc họp tại `media/07_meetings/%Y/%m/`.
