# Module 01: Layout Hệ thống & Dashboard
- **Trưởng nhóm:** Châu Tuấn Kiệt (PM)
- **Độ khó:** 0.6 / 0.8

## 1. Mục tiêu & Phạm vi
- Xây dựng Master Base Layout cho toàn bộ hệ thống QLVB&TL.
- Hỗ trợ responsive đa thiết bị (Desktop, Tablet, Mobile).
- Hỗ trợ 3 Theme: Light, Dark, Gray.
- Xây dựng Dashboard trung tâm tổng hợp thông số:
  - Thống kê văn bản đến, đi trong ngày/tháng.
  - Số lượng hồ sơ cần phê duyệt / trình ký.
  - Số lượng công việc được giao và hạn xử lý.
  - Lịch họp và thông báo sự kiện, sinh nhật trong ngày.
